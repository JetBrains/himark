# Air UI browser measurements

Generated from the original Air UI SCSS and component DOM at
`JetBrains/jcp-frontend@bca58ddb3f277265c479da7379d8a80572822985` with
`scripts/air-ui-reference.cjs`, Chromium 143.0.7499.0, CSS scale 1, in both
color schemes. The first six rows include a fifth column for the text baseline.

Columns are `x,y,width,height[,baseline]`. The specimen order is defined by
`air_reference_specimens` and the reference script: six typography roles,
three button variants × five states, three checkbox values × five states,
a list row, and three surfaces. Widths may differ by at most 1/32px due to
browser layout rounding. Heights and baselines must match exactly.

These are independent web reference measurements. The native gallery
baseline update flag deliberately does not overwrite them.
